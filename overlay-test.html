Проба: памятка поверх игры

Памятка открывается в отдельном окне, которое остаётся поверх остальных окон. Работает в Chrome и Edge на компьютере; игра должна быть запущена в окне без рамки.

В этом браузере окно поверх остальных открыть нельзя. Откройте эту страницу в Chrome или Edge на компьютере.

Окно не открылось. Попробуйте ещё раз или выберите другой размер.

  1. Нажмите одну из кнопок — появится окно с памяткой.
  2. Перетащите окно в удобное место; размер меняется за край окна.
  3. Зайдите в игру — окно останется сверху.
  4. Чтобы искать статью, перейдите в окно через Alt + Tab или щёлкните по нему. Вернуться в игру — щёлкнуть по игре.

Эту вкладку не закрывайте: окно закроется вместе с ней.
